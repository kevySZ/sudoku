# 每日数独

每日数独是一款免登录、无广告、离线可玩的 Android 数独 App。应用专注于安静、轻量的解题体验，支持难度选择、游戏存档、计时、错误限制、提示金币、最佳记录排行等核心玩法。

## 功能特性

- 四种难度：初级、中级、高级、噩梦。
- 随机生成题目，并通过求解器校验唯一解。
- 游戏计时仅在游戏界面可见且未暂停时递增。
- 每局最多允许 3 次错误，达到上限后本局结束。
- 任意格子可选中，支持行列十字高亮和相同数字高亮。
- 数字全部填完后，底部对应数字按钮自动隐藏。
- 支持暂停、锁屏、退后台和 `onStop` 场景下的本地存档。
- 首页支持继续未完成游戏。
- 最佳记录按难度保存前 10 名完成时间。
- 本地金币系统：首次赠送金币，通关按难度奖励金币。
- 提示系统：每局最多 3 次提示，每次消耗金币。
- 初级/中级支持九宫格最后一格辅助输入。
- 无广告 SDK、无登录依赖、无网络权限。

## 页面结构

- 首页：Logo、难度选择、开始游戏、继续游戏、最佳记录入口、金币余额。
- 游戏页：难度、金币、计时器、数独棋盘、数字键盘、提示、暂停、新局、首页、错误次数。
- 最佳记录页：展示各难度当前最佳时间。
- 最佳记录详情页：展示单个难度前 10 个最快完成时间。

## 玩法规则

### 难度

| 难度 | 挖空范围 | 通关金币奖励 |
| --- | --- | --- |
| 初级 | 36-40 | 20 |
| 中级 | 42-46 | 35 |
| 高级 | 48-52 | 55 |
| 噩梦 | 52-56 | 80 |

### 错误限制

每局游戏最多允许 3 次错误输入。错误输入不会写入棋盘，达到 3 次后游戏结束。

### 提示与金币

- 首次打开应用会初始化 30 金币。
- 每次提示消耗 15 金币。
- 每局最多使用 3 次提示。
- 提示会优先填入当前选中的空格；若当前格不可填，则自动选择一个未填空格。
- 金币和提示次数保存在本地，不依赖账号。

### 辅助策略

初级和中级难度下，如果选中的空格所在 3x3 九宫格已经填满 8 个数字，底部数字键会高亮唯一缺失数字。其他仍可见数字键隐藏文本并禁用；已经完成并隐藏的数字键不会重新占位。

高级和噩梦难度不启用该辅助策略。单行或单列最后一格也不触发该策略。

## 技术实现

- 语言：Java
- 平台：Android
- 最低版本：Android 9.0，`minSdk 28`
- 目标版本：`targetSdk 36`
- 构建系统：Gradle
- UI：原生 View 动态构建
- 数据存储：SharedPreferences
- 数独核心：本地生成完整终盘，再按难度挖空，并校验唯一解

## 项目结构

```text
app/src/main/java/com/kevy/sudoku/
├── MainActivity.java              # 页面、游戏状态、存档、金币、排行
├── SudokuBoardView.java           # 数独棋盘绘制和高亮交互
├── SudokuLogoView.java            # 首页 Logo 绘制
└── game/
    ├── Difficulty.java            # 难度配置
    ├── SudokuGenerator.java       # 题目生成和挖空
    ├── SudokuPuzzle.java          # 题目数据模型
    └── SudokuSolver.java          # 数独求解和唯一解校验
```

## 构建方式

使用 Android Studio 打开项目，等待 Gradle 同步完成后运行 `app` 模块即可。

也可以在项目根目录执行：

```powershell
.\gradlew.bat assembleDebug
```

Debug APK 通常生成在：

```text
app/build/outputs/apk/debug/
```

## 隐私说明

每日数独当前版本不接入登录、广告或网络能力，不声明网络权限。游戏题目、存档、金币、提示次数和最佳记录都保存在设备本地。

如后续接入微信或支付宝授权登录，需要增加服务端用于密钥保护、授权码换取 token、身份校验和账号绑定。客户端不应保存 app secret、私钥或长期 token。
